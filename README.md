# Delgender Communications - Backend

The backend repository for the **Delgender Communications** website.

Built with **.NET 10** and **PostgreSQL**, following a layered architecture consisting of:

* **API**
* **Application**
* **Core**
* **Infrastructure**

## Getting Started

To work on the repository, clone it and open the solution file in the root directory (`.slnx`) using your preferred IDE.

From there, restore the dependencies, configure the required environment variables, and run the application.
